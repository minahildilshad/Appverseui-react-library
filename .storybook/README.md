# AppverseUI React Component Library

A modern, production-ready TypeScript component library built for React with full keyboard accessibility, controlled/uncontrolled state support, Storybook stories, and React Testing Library test suites.

## Features
- **12 Production Components:** Button, Input, Select, Modal, Tooltip, Dropdown Menu, Data Table, Form (React Hook Form), Toast, Tabs, Accordion, DatePicker.
- **TypeScript Support:** Fully typed props interface and JSDoc annotations for every component.
- **Accessibility:** ARIA compliant design, keyboard navigation, and live regions.
- **Storybook:** Visual playground for testing and previewing UI primitives.
- **Testing:** Unit test coverage using React Testing Library and Jest.

## Quick Start
```bash
npm install
npm run storybook
npm test
